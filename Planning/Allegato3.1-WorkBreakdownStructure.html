Dettaglio Completo (Sottosistema → Funzione → Attività → Task)

1. Game Engine
1.1 Logica di Gioco Maraffone
1.1.1 Implementazione Regole Base
  • 1.1.1.1 Definire struttura dati per carte (seme, valore, ordine)
  • 1.1.1.2 Implementare mazzo da 40 carte italiane
  • 1.1.1.3 Implementare algoritmo di distribuzione carte (2×5)
  • 1.1.1.4 Codificare ordine di forza carte (3→2→A→Re→Cavallo→Fante→7→6→5→4)
1.1.2 Sistema di Punteggio
  • 1.1.2.1 Implementare calcolo punteggio carte (Asso=1pt, Figure/2/3=1/3pt)
  • 1.1.2.2 Sviluppare arrotondamento per difetto (punti interi)
  • 1.1.2.3 Implementare bonus ultima presa (+1 punto)
  • 1.1.2.4 Calcolare totale mano (max 11 e 2/3 punti)
1.1.3 Meccanica Turni
  • 1.1.3.1 Implementare selezione briscola da chi ha 4 di denari
  • 1.1.3.2 Validare obbligo di rispondere al seme
  • 1.1.3.3 Determinare vincitore presa (briscola vs seme)
  • 1.1.3.4 Gestire rotazione turni (senso antiorario)
1.1.4 Regole Speciali
  • 1.1.4.1 Rilevare Maraffa/Cricca (Asso+2+3 briscola)
  • 1.1.4.2 Validare obbligo gioco Asso se Maraffa
  • 1.1.4.3 Assegnare 3 punti bonus per Maraffa
  • 1.1.4.4 Penalizzare mancato gioco Asso (-3 punti)
1.1.5 Condizioni Vittoria
  • 1.1.5.1 Verificare raggiungimento 41 punti + figura
  • 1.1.5.2 Implementare variante corta (31 punti)
  • 1.1.5.3 Determinare coppia vincitrice
  • 1.1.5.4 Generare riepilogo fine partita
1.2 Validazione e Testing
1.2.1 Unit Testing Regole
  • 1.2.1.1 Test punteggio carte (30 test case)
  • 1.2.1.2 Test vincitore presa (briscola/seme)
  • 1.2.1.3 Test Maraffa/Cricca (casi positivi/negativi)
  • 1.2.1.4 Test condizioni vittoria
1.2.2 Integration Testing
  • 1.2.2.1 Test partita completa simulata (4 giocatori bot)
  • 1.2.2.2 Validare coerenza punteggi mano per mano
  • 1.2.2.3 Test edge cases (pareggi, carte finali)
